# Plan: HTTP from scratch

Write each section yourself, before you ask your agent for any code. Plain
words, no code. Give the agent this file along with your request.

## Milestone 1

### What it should do

> In your own words: what happens, step by step, from a connection opening to
> the connection closing?

### The cases I'll test

> At least four, each as "given this, I should get that". Include at least one
> case you think the agent might get wrong.

### Out of scope for now

> What you're deliberately not doing in this milestone.

### How I'll know it works

> The commands you'll run, and what you expect to see.

## Milestone 2

### What it should do

> Routes with named parts, files from the public folder, and every status code
> in the lesson. Write down which code each case gets.

### What my server refuses, and how

> Each thing you won't support, and the answer the server gives instead.

### The cases I'll test

> At least four more. Include at least one attack: a request someone sends on
> purpose to break your server or read a file they shouldn't.

### How I'll know it works

> The commands you'll run, and what you expect to see.
