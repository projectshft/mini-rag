# Decision memo: By-hand toolkit

Answer each question in a few sentences, in your own words. No agent.

## 1. Your queue

How did you store the items, and why is taking one off the front fast?
What would have been the simple way, and what does it cost on a long queue?

## 2. Your hash map

How does a key find its bucket? What happens when two keys land in the same one?
How many buckets did you choose, and what happens to speed as the map fills up?

## 3. Which one for the job

For each of these, name the structure you'd pick and say why in one sentence.

- The undo history in a text editor
- Print jobs waiting for a printer
- Looking up a customer by email address
- Checking whether you've seen a value before

## 4. What you'd do differently

One thing you'd change if you started this project again.
