## Who we are

## The problem

Entry-level software hiring has fallen sharply [CONFIRM: source for the figure we cite], and AI tools now write much of the routine code that junior developers used to be hired for. Most training options leave a gap:

- **Degrees** teach theory but not how the work is done today, where engineers direct AI tools and check what they produce.
- **Short AI courses** teach people to prompt a tool, but not to tell when its output is wrong.
- **Hiring processes** still test fundamentals by hand, with no AI allowed.

People changing careers, often older workers and those without a degree, fall through that gap.

## What the program does

The program takes someone with no coding experience and makes them employable as a software engineer who works with AI tools.

- **Fundamentals first, by hand.** Students learn how computers, networks and databases work, and write their first projects without AI, so they can judge the code AI writes later.
- **Then real software, built with AI tools.** Students plan features, direct an AI coding tool to build them, and prove the result works with tests.
- **Job readiness throughout.** Interview practice, Git and GitHub, LinkedIn and mock interviews run alongside the technical work from the start.
- **A capstone of their own:** a deployed product that uses real data, an AI agent and one technology they taught themselves.

## How students are supported

- Up to 12 one-on-one sessions with a working software engineer
- Weekly office hours and a monthly guest speaker from the industry
- Career support and mock interviews
- Internships with partner companies, which pay Parsity no referral fee when they hire a student [CONFIRM: still offered, and the number of cohorts to date]
- Self-paced, with no cohort start dates: as little as 12 weeks or up to a year, with support for 12 months. This lets students keep working while they train.

## How progress is measured

Every assignment is handed in as code and checked automatically, against tests the student can see and tests they can't. Students resubmit until the work passes. Each project ends with a short written explanation of the student's design decisions. This gives us an objective, per-student record of skills gained, which we can report to funders.
